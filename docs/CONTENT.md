# Готовим контент (библиотеку звуков)

Приложение не содержит музыки и звуков — вы указываете папку со своей библиотекой, приложение индексирует её. Файлы не копируются.

## Структура папок

```
<Библиотека>/
├── music/
│   ├── neutral/                           # центр колеса
│   ├── happy/    calm/  vivid-town/
│   ├── epic/     soaring/  epic/
│   ├── sad/      defeat/  tragic/
│   ├── tense/    thrilling/  tense/
│   ├── creepy/   eerie/  creepy/
│   ├── mystic/   spheric/  mystic/
│   ├── magical/  slight-magic/  magical/
│   ├── funny/    noble/  funny/
│   ├── transitions/  victory/  tragic-fight/  moody/  dread/
│   │                 haunted/  enchanted/  whimsical/  festive/
│   └── battle/                 # боевой режим: то же самое дерево внутри
│       └── epic/epic/, creepy/creepy/, …
├── ambience/
│   └── forest/                    # любое имя = название окружения
│       ├── cover.jpg              # обложка (необязательно)
│       ├── base.ogg               # бесшовная петля; или base_day.ogg + base_night.ogg
│       ├── spots/                 # случайные звуки: birds_01.ogg, birds_02.ogg → слой «birds»
│       └── layers/                # петли ручного включения: stream.ogg, campfire.ogg
├── weather/
│   └── rain/, storm/, wind/, snow/   # по подпапке на тип
└── sounds/
    └── creature/                  # категории: nature, human, animal, creature,
        └── goblin_01.ogg …        # attack, magical, mechanism
```

## Зоны колеса (25)

Колесо = нейтральный центр + 8 секторов × 2 ступени + 8 переходов между соседними
секторами. Имена папок, цвета и идентификаторы зон заданы в
`core/src/main/resources/wheel_zones.json` (источник правды); видимые названия —
в `strings.xml` по ключу `zone_<id>`.

- Трек попадает в зону по папке: `music/happy/vivid-town/` → зона `happy.vivid_town`,
  `music/transitions/victory/` → `transition.victory`, `music/neutral/` → центр.
- Файлы прямо в папке сектора (`music/happy/track.ogg`, без подпапки ступени) —
  **внешняя** ступень этого сектора.
- Позиция по умолчанию — детерминированный «разброс» внутри зоны по хэшу пути
  файла: повторное сканирование даёт ту же точку.
- Приоритет позиции: ручная из приложения → `meta.json` (`"wheel"` или `"zone"`) → папка.
- Неизвестная папка → трек импортируется «не размещённым» (не играет); в разделе
  «Библиотека» ему можно задать зону кнопкой «Выбрать зону».
- Заполнять все зоны не нужно: пустая зона играет ближайшую непустую этой же
  моды (разведка/бой), а на экране появляется подпись «Играет: <зона>».
- Ручные позиции (выбор зоны, перемещение) хранятся в базе и переживают
  пересканирование.

## Правила

- Название = имя файла без расширения и суффикса `_NN`; подчёркивания становятся пробелами.
- Файлы с одинаковым именем и разными номерами (`goblin_01.ogg`, `goblin_02.ogg`) — варианты одного звука: при каждом запуске выбирается случайный, не повторяющий предыдущий.
- Форматы: **ogg, opus** (рекомендуются — без пауз на стыке петель), mp3, flac, wav, m4a.
- Сравнение папок с зонами без учёта регистра; `-`, `_` и пробел равнозначны.

## Петли без стыков

MP3-энкодеры добавляют паддинг, из-за которого слышен «шов» в петле. Для `base` и слоёв `layers/` используйте **OGG Vorbis или Opus** — они стыкуются без пауз. Если файл всё же не бесшовный, положите рядом с ним `meta.json` с `"seamless": false` — base-луп перейдёт в запасной режим с перекрытием двух плееров (для него нужна длительность файла из индекса).

## meta.json (необязательно)

Положите `meta.json` в любую папку, чтобы переопределить автоматику:

```json
{
  "title": "Вечерний лес",
  "category": "nature",
  "wheel": { "x": 0.7, "y": 0.7 },
  "zone": "happy.vivid_town",
  "gainDb": -2.0,
  "random": { "minIntervalSec": 8, "maxIntervalSec": 25 },
  "seamless": false
}
```

Поля применяются к файлам рядом с json. Для музыки: `"wheel"` задаёт точку на
колесе (x, y в единичном круге), `"zone"` — зону по id из `wheel_zones.json`
(позиция берётся по умолчанию для зоны). `seamless` работает только в папке
окружения (управляет base-лупом).

Для одиночных звуков (`sounds/<категория>/`) работают поля `title`, `icon`, `gainDb` и объект
`random` с джиттером громкости, панорамы и тона:

```json
{
  "title": "Гоблин",
  "random": { "gainJitterDb": 4, "panJitter": 0.6, "pitchJitterPct": 8 }
}
```

`gainJitterDb` — разброс громкости в ±дБ, `panJitter` — ±смещение панорамы (0..1),
`pitchJitterPct` — ±% скорости. Без `random` звук играется ровно как записан.

## Где брать легальные звуки

Freesound, OpenGameArt, Incompetech, Soniss GDC-релизы и др. **Проверяйте лицензию каждого файла** (CC0 / CC-BY / CC-BY-SA и условия атрибуции) — приложение не контролирует лицензии вашей библиотеки.
