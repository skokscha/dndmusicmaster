# Архитектура

*(Документ развивается по мере этапов.)*

## Модули

- **`:core`** — чистый Kotlin/JVM, без `android.*`: модели, геометрия колеса, выбор треков, микшерная математика, правила библиотеки, интерфейсы `AudioEngine` и репозиториев. Покрывается unit-тестами.
- **`:app`** — Android-приложение: реализация `AudioEngine` (Media3 + SoundPool), Room/DataStore/SAF, Compose UI. Здесь позже появится третий модуль `:desktop` — поэтому вся логика обязана жить в `:core`.

## Поток данных

`UI (Compose) → ViewModel (StateFlow) → AudioEngine / Repository (интерфейсы из :core) → реализации в :app`

## Аудио

- Шины: `MASTER → { MUSIC, AMBIENCE, SFX }`, значения в dB, в плееры — линейные.
- Музыка: два плеера A/B с equal-power кроссфейдом (`cos/sin(t·π/2)`).
- Окружение: до 6 петель ExoPlayer + SoundPool для случайных спотов.
- Одиночные звуки: SoundPool, полифония ~8 потоков.
- Аудиофокус: один менеджер на движок, опция «играть вместе с другими приложениями».

Подробнее по мере реализации: этапы 4–5 добавят детали движка, этап 3 — схему Room.
