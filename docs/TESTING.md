## Этап 4 — музыкальный движок и колесо
- [ ] Перетаскивание маркера: через ~0.6 с после остановки трек выбран и начинает играть (сначала тишь → нарастание)
- [ ] Малые сдвиги маркера (в пределах 0.4 от точки выбора) не переключают трек
- [ ] Резкий перенос маркера в другой сектор → кроссфейд ~4 с без щелчков, громкость не «проваливается»
- [ ] Центр колеса (спокойствие) выбирает треки из calm-папки
- [ ] «Бой» играет только треки battle-папки, «Разведка» — только обычные; у каждого режима своя последняя точка
- [ ] «Следующий» меняет трек без повтора последних пяти
- [ ] По окончании трека включается следующий автоматически
- [ ] Пауза/Продолжить работают; после продолжения громкость возвращается плавно
- [ ] Поворот экрана не прерывает воспроизведение
- [ ] Для пустой зоны показывается «Ничего не играет», ошибок воспроизведения нет

## Этап 5 — движок окружения
- [ ] Выбор окружения: base-луп стартует с нарастанием, повторяется без стыка (OGG)
- [ ] День/ночь: base меняется «через тишину», слои не прерываются
- [ ] LOOP-слои включаются/выключаются с плавным фейдом, слайдер громкости работает
- [ ] Споты (birds) звучат сами через интервалы, варианты не повторяются подряд, тон/громкость слегка «плавают»
- [ ] Погода (дождь/гроза/ветер/снег) включается поверх окружения, «Ясно» выключает
- [ ] Пауза/продолжение окружения: споты после продолжения не залипают в слотах
- [ ] meta.json с `"seamless": false` переключает base на фолбэк-лупер (стык без паузы)
- [ ] Музыка и окружение звучат одновременно, не глушат друг друга
